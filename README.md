# NEB Computer Science Education Website

Production-ready educational website for **NEB Nepal Grade 11 & 12 Computer Science** students built with **HTML/CSS/JavaScript + PHP + MySQL**.

## Features

- Landing page with responsive design, animations, and dark/light mode
- Grade 11 (10 chapters) and Grade 12 (8 chapters) interactive chapter content
- Chapter-level MCQ quizzes with instant feedback
- 50+ past questions per grade with filters, search, and learned progress
- Labs: C Programming (30+ exercises), HTML/CSS live editor, PHP lessons
- Quiz engine with 200+ MCQ data and leaderboard integration
- Educational games (binary, memory match, blitz, topology)
- Leaderboard with localStorage and API fallback
- PHP admin dashboard with login, CSRF protection, charts, and management pages
- MySQL schema with seed data and API endpoints

## Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- PHP 8+
- MySQL/MariaDB
- Bootstrap 5, Font Awesome 6, AOS, Chart.js, CodeMirror (CDN)
